## Hinweise

- Die Seiten sind **Muster**, kein offizieller Auftritt der Betriebe.
- `robots: noindex` auf der Übersicht, damit nichts davon in der Suche landet.
- Impressum und Datenschutz enthalten Platzhalter in eckigen Klammern. Vor
  einem echten Livegang müssen die vom Inhaber ausgefüllt werden.
- Kein Tracking, keine Cookies, keine externen Skripte.

## Struktur

Jede Seite liegt in einem eigenen Ordner mit allen Dateien, die sie braucht.
Rein statisch, kein Build-Schritt. Neue Seite = neuer Ordner plus eine Zeile in
`index.html`.
